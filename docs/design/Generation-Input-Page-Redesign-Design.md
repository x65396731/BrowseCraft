# 网址输入页与引导屏的视觉与信息结构重设计

设计稿（画布，含空输入、已贴入、检查中、四种结论、提交中、三种提交结果、coin 不足、网址错误、深色与引导屏，共 14 张）：
[网址输入页重设计](https://claude.ai/artifact/UuQgufr1D7PNb8AgQ2b1C4)；设计文档：[网址输入页重设计](https://claude.ai/artifact/6XzaSo3VD3eWdBgwaoG2f5)。
设计与实施状态见 [STATUS.md](../STATUS.md)。颜色、圆角、字号与交互约定沿用添加来源页与云同步页
（[添加来源页](Add-Source-Page-Redesign-Design.md)、[云同步页](Cloud-Sync-Page-Redesign-Design.md)）。

## 一、背景

`VideoGenerationInputView` 曾是一个系统 `Form`，按状态轮流出现五个分组：网址输入框、「检查网站 / 取消检查 / 怎样的页面能生成？」、检查进度、
状态（结论 + 取页方式 + coin + 生成按钮 + 提交结果）、状态（错误 + 重试）。三种类型共用同一页，只换导航栏标题「视频 / 漫画 / 书籍」。

- 添加来源页已是自绘大标题与卡片，在同一层 sheet 里接着出现的这一页还是系统表单。
- 标题只有一个字，看不出这页在做什么。
- 结论、提交前选项、提交结果挤在一个分组里，可以生成时有八行，主按钮「生成规则」是最后一行蓝字。
- 颜色用系统绿 / 橙 / 红，不是 `CatalogPalette` 的取值。
- 网址要手打或长按粘贴，没有粘贴按钮。
- 网址写错与页面不合格是两个同名分组「状态」，看起来是同一类事。
- 引导屏（首次必过一屏与回看）也是系统表单，夹在两屏新样式之间。

## 二、入口、流程与范围

只有一个入口：添加来源页选了类型之后在同一层 sheet 里接着出现；首次先过引导屏。流程：贴网址 → 本机检查（不联网到服务器、不花 coin）→ 看结论 →
可以生成时选取页方式、滑动提交 → 提交成功停 1.2 秒后整个 sheet 收起回来源页，其他结果留在本页。

本文覆盖输入页全部状态与引导屏的外观（2026-10-06 用户裁定六项全取 A）。引导屏的文案、版本号与「首次必过」的判定（`BC-PAGE-060`）不动。

## 三、页面内容

页面跟随系统深浅，底色与卡片底取系统分组背景，颜色全部取 `CatalogPalette`，不新增。总原则：**一个阶段一张卡，任何时候页面上只有一个主控件**。

| 块 | 内容 | 取值与组件 |
| --- | --- | --- |
| 顶部 | 左上「关闭」；自绘大标题「生成视频规则」（按类型换词），标题前一枚 28pt 类型色图标圆；一句说明「贴一个带页码的列表页地址，先在本机检查，不花 coin。」。出了结论或结果之后说明句收起 | `largeTitle` heavy；图标圆取 `CatalogKindStyle.accent` 字 + 16% 底 |
| 网址卡 | 圆角 18 卡片：左侧链接图标、输入框（占位「带页码的列表页地址」）、右侧系统粘贴按钮（输入为空时显示，剪贴板为空时由系统按钮自行禁用；点了即填入并开始检查）或清除 ⓧ；检查中与提交中整卡变淡、禁用。卡下一行链接「怎样的页面能生成？」，出了结论后收起 | 系统 `PasteButton`（不弹授权）；链接动作蓝，叠一层引导屏 |
| 主按钮 | 蓝色胶囊「检查网站」，空输入时变淡禁用；手打的网址点按钮或回车开始检查。检查中换次级样式「取消检查」；还没看清换「再检查一次」 | 高 50 |
| 进度卡 | 检查中网址卡下一张卡：四步纵向清单（校验地址 → 隔离加载页面 → 检查列表结构 → 确认页面上的列表），做完的打勾、当前的转圈、未到的灰；卡下一句「只检查这一个地址，不搜索、不推荐别的页面。」 | 卡片组行；转圈取动作蓝 |
| 结论卡 | 检查完换成结论卡，与云同步页状态卡同一套（56pt 圆图标 + 标题 + 一句原因）：**可以生成**（蓝 ✓）、**这一页不能用**（警示橙 ✗，原因按 8 种换词，卡内链接「看看怎样的页面能生成」，卡下一句「改一下上面的网址，就会回到「检查网站」」）、**还没看清这一页**（警示橙 ?）、**有反爬验证，可以直接提交**（蓝盾）。警示态卡加警示色描边 | 共用 `StatusCardView`；不用绿、不用红 |
| 取页方式卡 | 只在可提交时出现。分区标题「取页方式」+ 卡片：两个胶囊按钮「普通 · 100 coin」「困难 · 300 coin」（2026-10-07 用户裁定：从点阵滑杆改回按钮，只有困难按钮带效果，且不要点阵流光那种动画）。普通 = 素底，选中时添加蓝 12% 底 + 蓝字 + 蓝描边；困难 = 粉彩渐变淡底（`CatalogPalette.spectrumFill`，#7FA8F7 → #B9A3F5 → #F2A8C8 → #F8C38F 的 16%）+ 渐变发光描边（`SpectrumGlowBorder`，饱和渐变 #2563EB → #7C3AED → #E0457B → #F28C28 沿胶囊描一圈、方向约 2 秒来回摆动一次、外加粉彩光晕，与内购页套餐按钮同一种语言），选中时描边更粗更亮、字用饱和渐变；不用黄 / 橙。系统「减弱动态效果」打开时描边不摆动。选困难时卡内多一句说明，反爬时再多一句警示色。卡下一行「当前余额 M · 生成可能失败，失败也会扣 coin。」，余额未知时只写后半句 | 新组件 `GenerationTierPicker`；价格取服务端 `pricing` |
| 滑动确认 | 可提交时主控件是滑动确认：胶囊轨道、左端 44pt 圆形滑块带箭头、中间「滑动生成 · 100 coin」（价格随档位变）；拖到右端打一次触觉反馈再提交，没拖到底松手弹回；拖动中跟手，松手才走弹簧。两套视觉：普通档添加蓝 12% 底、蓝滑块白箭头、蓝字；困难档粉彩渐变淡底铺流光点阵（`DotMatrixTrack`，一道光斑约 2 秒扫一遍，扫过的点变亮略变大）+ 饱和渐变文字与滑块，不加渐变发光描边（用户 2026-10-07 认可的那版，描边只给困难按钮；系统「减弱动态效果」打开、禁用或进行中时静止）。提交中滑块停在右端内转圈、文字换「正在提交…」。规则已存在时写「滑动重新生成 · N coin」，提交失败时写「滑动再试一次 · N coin」 | 新组件 `SlideToConfirmControl`；只有扣 coin 的动作要滑 |
| 提交结果 | 替换结论卡：**生成任务已提交**（蓝纸飞机，「生成完成后会出现在规则目录「我的生成」里」+ 小字「正在回到来源页…」）；**规则已存在**（蓝 ✓，写规则名，卡下一句说明可重新生成）；**需要登录 / 任务已达上限 / 上一个任务还没完成 / 提交太频繁 / coin 不足**（警示橙，无主控件，coin 不足的文案带「看完激励广告可获得 coin」）；**提交没有成功**（警示橙，滑动再试一次） | 同一套状态卡 |
| 网址错误 | 网址无效 / 非 HTTP / 不安全 / 非 HTML / 404 / 403 / 429 / 5xx / 请求失败：不出卡，网址卡加警示色描边，卡下一行警示色小字；主按钮回到「检查网站」 | 警示色文字与描边 |

- 改网址即清空结论与提交状态，回到只有网址卡 + 「检查网站」的状态（与现状相同）。
- 任务客户端未接线时（只在测试替身下出现）主控件禁用并保留现有一句说明。
- **引导屏**：自绘大标题「怎样的页面能生成」，一句说明，顶部插画不动；「两条要求」做成两行卡片组（32pt 图标方块 + 标题 + 说明），组下一句提醒；
  「例子」两行（✗ 警示橙 / ✓ 动作蓝）；「怎么找」三行带序号圆；底部蓝色主按钮「我找到了这样的页面」或「知道了」。首屏左上「取消」关掉整个流程，回看形态没有取消。

## 四、不改的东西

- 预检的判定与四步流程、结论与原因的含义、反爬放行、提交串的取法（fwq `BC-PREFLIGHT-*` 与 `BC-ACQ-071`）。
- 提交逻辑、提交结果的来源、重新生成、价格与余额的来源；提交成功 1.2 秒后自动回来源页；规则已存在时不自动添加成来源。
- 引导屏的文案、版本号与「首次必过」的判定；目录页失败行与空状态里打开引导屏的入口。
- 「离开即结束整个流程」的关闭纪律；输入页不能退回改类型。

## 五、实现位置

- `BrowseCraft/Features/Sources/AddSource/VideoGenerationInputView.swift`：整页重画，状态机不动。
- `BrowseCraft/Features/Sources/AddSource/EntryPageGuideView.swift`：引导屏按第三节重画；`EntryPageGuideFlowView` 不动。
- `BrowseCraft/Features/Shared/StatusCardView.swift`：从云同步页抽出的状态卡，云同步页改为复用。
- `BrowseCraft/Features/Shared/SpectrumGlowBorder.swift`：渐变发光描边，只给困难按钮。
- `BrowseCraft/Features/Shared/DotMatrixTrack.swift`：流光点阵（`TimelineView` 驱动 `Canvas`），只给困难档滑动确认用。
- `BrowseCraft/Features/Shared/GenerationTierPicker.swift`、`BrowseCraft/Features/Shared/SlideToConfirmControl.swift`：两个新组件，实施后补进页面设计索引的可复用组件表。
- 三份 `Localizable.strings`：标题三句、说明、四步名、结论标题改词、档位与余额、滑动文案、结果标题；引导屏步骤去掉序号前缀；删去不再使用的词条。

## 六、真机验收清单

- 模拟器没走到：检查中的四步进度卡（检查太快抓不到）、真实提交的各结果态（要扣 coin）、粘贴按钮（模拟器剪贴板不同步）、coin 不足。
- 网址错误不出卡；困难档的渐变描边与流光点阵；滑动确认拖一半弹回；引导屏回看形态。深色模式整页看一遍。
