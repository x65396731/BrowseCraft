# 历史页的视觉与信息结构重设计

设计稿（画布，含浅色 / 深色、只看视频、左滑删除、撤销、长按菜单、来源状态与临时资源、空状态、某类型为 0、只有一条，共 10 张）：
[历史页重设计](https://claude.ai/artifact/BfAD7W4ovf5774BuM8PeTn)；设计文档：[历史页重设计](https://claude.ai/artifact/Esg7q9EHGvHEPZDMtDiK1w)。
设计与实施状态见 [STATUS.md](../STATUS.md)。颜色、圆角、字号、组件与交互约定沿用来源页、规则目录页与收藏页
（[来源页](Sources-Page-Redesign-Design.md)、[规则目录页](Catalog-Page-Redesign-Design.md)第三节、[收藏页](Favorites-Page-Redesign-Design.md)），本页不新增颜色。

## 一、背景

`HistoryView` 曾是一个系统分组列表，每行画成「灰色类型图标 + 作品名 / 章节名 / 来源名 / 完整日期时间」四行，
与重设计后的来源页、收藏页、规则目录页并排在底栏时反差明显：

- 导航栏大标题「历史」下面又有一个分组头「最近看过」。
- 四种历史都存了封面地址，页面只显示文字；类型只靠灰色小图标区分。
- 视频存了播放位置与时长、漫画存了页码，页面都不显示，看不出看到哪里。
- 删除只有系统左滑、没有撤销；漫画删除只删最后一章那条记录，刷新后同一本漫画的上一章重新出现。
- 来源已暂停或已删除时行看起来一样，点进去才失败。

历史只存本机、不走 iCloud 同步，所以本页没有「首次恢复」状态。

## 二、信息结构

### 2.1 顶部

- 大标题「历史」靠左，在内容里自绘；右侧一个小字「N 条」。
- 标题下一个分段筛选「全部 | 视频 | 漫画 | 书籍」，共用 `CatalogSegmentedPicker`，每段带计数，四段一直显示，没有历史的类型计数为 0。
- 临时资源按自身类型归入「视频」或「漫画」，不单独开一段。

### 2.2 继续卡片

- 当前筛选下最近的一条放在筛选与列表之间，用该条类型的深色类型瓷砖（与来源页「正在使用」同一个 `.sourceTile(style:)`）：
  左封面 72×100pt、圆角 12，右侧从上到下是色块强调色小字「上次看到」（视频）或「上次读到」（漫画、书）、作品名、看到哪里、
  视频进度条（4pt）、「来源 · 时刻」。
- 卡片上不放按钮：整张卡片就是点击区，与点列表行同一条路径（2026-10-03 用户裁定）。
- 这一条不在下方列表重复出现；卡片不支持左滑，长按菜单与列表行相同。

### 2.3 列表

- 继续卡片以外的条目按访问时间倒序、按天分组：「今天」「昨天」，更早的写「M月D日」，跨年时带年份；组头共用 `CatalogDayTitle`。
  只按天分组，不按来源分组（2026-10-03 用户裁定）。
- 同一天的行拼成一张圆角 18 的卡片组：首行圆上角、末行圆下角，行间细线从 82pt 起，与收藏页同一个卡片组行。
- 一行是一部作品：视频按作品、漫画按漫画只留最近一条，书本来一本一条。

### 2.4 卡片行

| 位置 | 内容 |
| --- | --- |
| 左 | 封面 56×78pt，圆角 10，经 `ItemThumbnailImageView` 走库页同一个封面管线，请求配置取该来源规则的图片请求配置；无封面时退回该类型的占位图 |
| 封面左下角 | 18pt 类型徽标：类型色底 + 类型图标 |
| 封面底边 | 仅视频且知道时长：3pt 进度条，已看部分为类型色，轨道为半透明黑 |
| 中·第一行 | 作品名，最多两行 |
| 中·第二行 | 看到哪里（见下表），没有就不显示 |
| 中·第三行 | 「来源名 · 时刻」；临时资源为「主机名 · 时刻」 |
| 右 | › |

第二行只用历史里已有的字段，不新增存储：

| 类型 | 显示 |
| --- | --- |
| 视频 | 「第12集 · 看到 23:14 / 45:00」；没有时长时只写「看到 23:14」，不画进度条；看到时长的 95% 及以后写「第12集 · 已看完」 |
| 漫画 | 「#092 · 第 18 页」；没有页码时只写章节名 |
| 书籍 | 「读到 第三章」；没有章节名时不显示此行 |
| 临时资源 | 「临时视频」或「临时漫画」 |

### 2.5 点击语义

- **点行或继续卡片**：接着看。漫画进阅读器、书进站点书阅读器、视频开全屏播放器、临时资源进它的详情页。
- **左滑**：「删除」，按钮为删除色 `#E5484D`，不弹确认（2026-10-03 用户裁定）。
- **长按菜单**：「继续看」（漫画、书为「继续读」）、「在库中查看来源」（切到该来源并打开库，与收藏页同一条路径；临时资源没有此项）、
  分隔开的红色「删除记录」。
- **撤销**：删除后底部出现反色胶囊提示「已删除「作品名」的记录 · 撤销」，约 4 秒后消失。

## 三、删除与撤销的语义

- 删除以作品为单位：删一行就删掉这部作品在该历史表里的全部记录（漫画的全部章节记录、视频的全部剧集记录），刷新后不得再冒出上一章或上一集。
  `DeleteReadingHistoryEntryUseCase` 先按作品键从仓储取出同作品的全部记录，再在该表的一个写事务里批量删除，并把被删的记录作为
  `ReadingHistoryRemoval` 交回。
- 撤销由 `RestoreReadingHistoryUseCase` 把 `ReadingHistoryRemoval` 里的记录原样写回，含原访问时间，条目回到原来的日期分组。
  视频仓储保存时按作品覆盖旧记录，所以视频记录按更新时间从旧到新写回，留下的是最近一条。
- 删除历史不动 Source、收藏与站点书续读位置。
- 删除是可撤回的轻操作，沿用收藏页「不弹确认 + 底部撤销」。
  本页不提供「清空历史」（2026-10-03 用户裁定）。

## 四、其余状态

| 场景 | 显示 |
| --- | --- |
| 没有历史 | 插画 `EmptyStateHistory` +「还没有历史」+ 一句说明，下面一张入口卡片「去库里逛逛」切到库标签；空状态放在滚动内容里，不显示继续卡片与筛选 |
| 某个类型没有历史 | 该标签下显示小空状态：类型图标 +「还没有看过的视频」等 + 一句说明，不用插画；删除使当前类型变空时停在该标签 |
| 只有一条 | 只有继续卡片，下方不画分组头 |
| 来源已暂停（位置不够） | 来源名后加橙色「· 已暂停」；点行打开来源页的启用来源窗口，不进一个打不开的阅读器 |
| 来源已删除 | 用历史里保存的来源快照照常显示，来源名后加「· 来源已删除」，整行变淡；点行仍用快照尝试打开 |
| 来源找不到且没有快照 | 来源名显示「未知来源」，整行变淡、没有 ›，点行无反应，只能左滑或长按删除 |
| 临时资源 | 没有来源状态，第三行是主机名；长按菜单没有「在库中查看来源」 |
| 加载失败 | 弹错；下拉重读本地历史 |

刷新一律用下拉，不加刷新按钮；本地读取足够快，不画骨架。

## 五、实现位置

- `BrowseCraft/Features/History/HistoryView.swift`：顶部、类型筛选、继续卡片、按天分组的卡片行、左滑与长按、撤销提示、空状态与小空状态、阅读器目的地。
- `BrowseCraft/Features/History/HistoryViewModel.swift`：筛选计数、继续条目、按天分组、看到哪里与视频进度、来源状态、封面请求配置缓存、删除与撤销。
- `BrowseCraft/Features/History/Components/HistoryEntryRowView.swift`：`HistoryEntryRowView` 与 `HistoryContinueTileView`。
- `BrowseCraft/Features/Shared/ContentCardComponents.swift`：收藏页与历史页共用的 `ContentCoverView`（封面 + 类型徽标 + 可选进度条）、
  卡片组行与列表行修饰、`ContentUndoBanner`。
- `BrowseCraft/Application/UseCases/History/ReadingHistoryUseCases.swift` 与 `HistoryPersistenceCoordinator.swift`：按作品删除、交回被删记录、撤销写回。
- `BrowseCraft/App/RootView.swift`：历史页请求「去库里逛逛」「在库中查看来源」「启用来源」时切标签，与收藏页同一处。
