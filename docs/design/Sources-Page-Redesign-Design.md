# 来源页的视觉与信息结构重设计

设计稿（画布，含三个方向、方案 A 的全部状态、启用来源窗口与插画设定）：[来源页重设计](https://claude.ai/artifact/WN7qaWyLwTjia1Rfx81Xwu)。
本文以方案 A 为准。设计与实施状态见 [STATUS.md](../STATUS.md)。

## 一、背景

`SourcesView` 是一个分组 List，每行由 `SourceRowView` 画成「勾选圆 + 名称 + 完整地址 + 状态字」，右侧一个 ⓘ 与 ›。问题有四个：

- **当前来源不显眼**：正在使用的来源与其他来源同一种行，只靠一个绿色勾区分。
- **点来源不去库**：点其他来源只切换（加载第一页、发布库快照），页面停在来源页；点当前来源什么也不发生。
  用户想看内容时要再点底栏「库」，于是「看这个来源」被拆成两步。
- **来源位置藏在导航栏中间**：「1 / 1 已用来源位置」是导航栏的标题位，位置满了以后要走完添加流程才看到
  `source_error_slot_limit_reached` 的报错。
- **ⓘ 与「打开」争位置**：ⓘ 打开的是 `SourceDebugView`（规则集、请求配置、分类试跑、只读 JSON），是排查工具，
  却与整行点击一样显眼；左上角的目录按钮用的系统图标与漫画详情的「章节列表」相同，含义模糊。

## 二、信息结构（方案 A）

### 2.1 顶部

- 大标题「来源」靠左；右上一个分段胶囊「✦ 目录 | ＋ 添加」：同一底色、同一字号字重，中间细分隔线，两段等权。
  「目录」打开 `CatalogSourceListView`，图标与目录页「推荐」标签相同；「添加」打开 `AddSourceView`。
- 标题下一条来源位置条：左「已用来源位置」、右「已用 / 上限」，下面一条进度条，最右「更多位置」，进入既有的高级版购买入口。

### 2.2 正在使用

- 一张类型色深色瓷砖卡片：底色、右上光圈、「正在使用」徽章与副标题随来源类型取色（视频琥珀、漫画淡紫、书籍青绿），
  取值与规则目录的类型横幅完全相同（`CatalogKindStyle` 的横幅取值，固定深色，不随系统变）。
- 卡片内容：首字徽标、站点名、「类型 · 出身 · 主机名」，底部「点卡片打开库 ›」。出身为「我的生成」或「来自目录」。

### 2.3 其他来源与点击语义

- 其他来源为一组卡片行：首字徽标（类型色）、站点名、「类型 · 出身 · 主机名」、末尾 ›。行上不再有 ⓘ。
- **点任意来源 = 用它打开库**：点当前来源直接切到库标签；点其他来源先切换（`selectSourceAfterRefresh`），
  成功后再切到库标签。切换失败时留在来源页并照现状给出错误，不跳到一个空的库。
- 切换中：被点的行底色变浅蓝、右侧转圈、说明换成「正在加载第一页，完成后自动打开库…」；其余卡片与行变淡且不可点
  （沿用 `isRefreshing` 的禁用）。

### 2.4 已暂停

- 因位置不够被锁定的来源单独一区「已暂停 · 位置不够」，行为锁形图标、站点名、「类型 · 出身」与一个按钮：
  有空余位置（`canActivateRequestedSourceWithoutReplacement`）时写「启用」，位置已满时写「替换使用」。两者都打开 2.6 的窗口。

### 2.5 长按菜单与删除

- 长按任意来源弹出菜单：第一项按状态为「打开库」（当前来源）/「切换并打开库」（其他来源）/「启用」或「替换使用」（已暂停）；
  其后是「来源详情」（`SourceDebugView`，正式版保留，2026-10-01 用户裁定）与分隔开的红色「删除来源」。
- 左滑删除保留。左滑与长按「删除来源」都直接删除，不弹确认（2026-10-03 用户裁定），删除后底部给「已删除「来源名」 · 撤销」，约 4 秒；页面底部的说明写明删除来源会同时删除它的阅读 / 观看历史和收藏（连带删除见 [删除来源时连带删除历史与收藏](Source-Deletion-Cascade-Design.md)）。

### 2.6 启用来源窗口

`SourceSlotActivationView` 的逻辑不变（`activateRequestedSource`），外观改为方案 A 的语言：

- 顶部为被暂停来源的类型色深色卡片，徽章「已暂停 · 类型」，下面一句「这个来源已经安全保存，只是暂时没有占用位置」。
- 位置已满：标题「位置已满 · 选一个来源让出位置」，列出正在使用的来源，每行末尾「换下」；底部说明被换下的来源不会删除、
  会移到「已暂停」，并附「获取更多位置」。
- 有空余位置：列表换成一个「启用这个来源」按钮与「还有 1 个空闲的来源位置」。

### 2.7 其余状态

| 场景 | 显示 |
| --- | --- |
| 没有来源 | 标题行照常，右侧仍写位置计数「0 / N 位置」；下面插画 + 「还没有来源」+ 一句说明；两张入口卡片「从规则目录挑一个」（打开 `CatalogSourceListView`）与「用网址生成」（打开 `AddSourceView`） |
| 位置已满且只有一个来源 | 位置条 + 正在使用卡片 + 提示卡「想再加一个网站？」：说明位置已满，可先长按删除当前来源，或获取更多位置 |
| iCloud 首次恢复 | 位置条显示「— / —」，中部为 `CloudSyncInitialRestoreView` 的等待 / 恢复中卡片与两条骨架；失败时显示原因与「下拉可重试」 |

恢复失败的「重试」按钮改为下拉重试。`CloudSyncInitialRestoreView` 由来源页与收藏页共用，两处一起改：卡片里不再有可点的控件；两页的恢复态都是独立的一页 `ScrollView`（标题行 + 卡片 + 两条骨架），不再叠在列表上，下拉直接落在这一页；收藏页恢复失败时下拉是重试，其余时候下拉重新读本地收藏。

## 三、视觉

- 来源页跟随系统外观；页面与卡片底色取系统分组背景。页面之间的主题色不能差异过大：来源页与从它弹出的规则目录页
  用同一套颜色——卡片上的类型色取 `CatalogKindStyle` 的随系统取值，「正在使用」与启用窗口顶部的深色瓷砖取横幅的固定深色取值。
- 动作色：添加按钮与链接为蓝 #2563EB；已暂停区与「替换使用」为橙（浅色 #C2410C，深色 #FF8A70）。
- 圆角：瓷砖卡片 24，列表卡片 18，位置条 14；触控目标不小于 44pt。

## 四、插画

空状态插画沿用资产名 `EmptyStateSources`，替换原图。原图「看板娘抱空箱子」与规则目录推荐空状态构思重复，改为新构思
（推荐「传送门」：推开一扇发光的半开小门，门里飘出空白网页卡片）；即梦提示词与设置见设计稿的「来源空状态插画 · 即梦设定」画板。
规格与其余空状态插画相同：透明底、540px 高、按 180pt 显示；替换时同步更新资源登记里它的尺寸与字节上限。

## 五、不变的部分

- 来源的数据、位置上限与锁定判定、启用 / 替换逻辑不变；本设计只改信息组织、外观与「点来源去库」这一步跳转。删除来源的连带删除按 [删除来源时连带删除历史与收藏](Source-Deletion-Cascade-Design.md) 执行。
- App 不提供规则创建或编辑入口（`BCA-UI-003`）；来源详情只读。

## 六、实现位置

- `BrowseCraft/Features/Sources/SourcesView.swift`：顶部按钮、位置条、正在使用卡片、分区、长按菜单、空状态与启用窗口。
- `BrowseCraft/Features/Sources/SourceRowView.swift`：按 2.3 / 2.4 重画行。
- `BrowseCraft/App/RootView.swift`：来源页请求打开库时切到库标签（与 `latestSourceAddID` 触发的跳转同一处）。
- `BrowseCraft/Features/Shared/CloudSyncInitialRestoreView.swift`：失败态改为下拉重试。
- 类型色复用 `BrowseCraft/Features/Sources/Catalog/CatalogStyle.swift`，不另起一套。

## 七、真机验收清单

模拟器已走通的流程见 [STATUS.md](../STATUS.md) 第 2 节；真机按下列看点验收，结果新增 `device-passed` 行、不改模拟器那行。

- 点其他来源切换成功后跳库、失败留在原页；「更多位置」切到设置页并打开购买页。
- 正在使用的深色瓷砖与类型色；已暂停一组与启用窗口。
- 长按菜单与左滑删除：删除色、不弹确认；连带删除后历史与收藏一并消失，撤销后都回来。
- 深色模式整页看一遍。
- 与设计稿的已知出入，不算缺陷：已暂停一组没有虚线外框；启用窗口里启用后不跳库；iOS 26 / 27 上左滑按钮是系统圆形样式。
