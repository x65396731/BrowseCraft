# coin 记录页的视觉与信息结构重设计

设计稿（画布，含浅色 / 深色记录、首次加载骨架、加载失败可下拉重试、没有记录、翻页中，共 6 张）：
[coin 记录页重设计](https://claude.ai/artifact/G5gdgxks5F9XcFRmRdyty3)；设计文档：[coin 记录页重设计](https://claude.ai/artifact/NJCeYe4DVK5RLo1fcPXhqh)。
设计与实施状态见 [STATUS.md](../STATUS.md)。颜色、圆角、字号与交互约定沿用设置页与历史页
（[设置页](Settings-Page-Redesign-Design.md)、[历史页](History-Page-Redesign-Design.md)）。

## 一、背景

`CoinLedgerView` 曾是一个系统 `insetGrouped` 列表，从重做后的设置页推进来时反差明显：

- 失败页写着「请检查网络后下拉重试」，但只有加载成功的列表能下拉，失败页与空页拉不动。
- 这是设置里的二级页，底栏五个标签仍压在列表上，还盖住最后一行。
- 看不到当前余额，也看不到一次生成、一次广告各值多少。
- 每行都写完整的日期与时刻，同一天的几行重复同一串日期。
- 获得与消耗只靠数字颜色区分，「生成失败退回」和「规则生成」成对出现时分不清；绿色写死在行里，不在 `CatalogPalette`。
- 加载中只有居中转圈，加载完成时整页跳一下。

本页只改展示层。数据仍是服务端为准、时间倒序、按游标翻页（`CoinLedgerViewModel`），本地不缓存。

## 二、导航

- 从设置页账号卡「coin 记录 ›」推入。进入后隐藏底栏，左上角系统返回是唯一出口，左缘右滑同样返回（2026-10-03 用户裁定）；
  返回设置页时底栏自动回来。
- 导航栏只有返回与居中小标题「coin 记录」，不自绘大标题——大标题只用在底栏五个标签的首页。
- 设置页给底栏设可见性（打开内购页时隐藏）只能挂在 `NavigationStack` 里的根页上，且不打开内购页时取 `.automatic`：
  挂在栈外面或写成显式 `.visible`，都会盖过本页自己的隐藏，底栏藏不掉。
- 页面内没有任何离开本页的链接，看广告留在设置页账号卡上。

## 三、信息结构

### 3.1 余额卡

- 小字「当前余额」，下面大数字余额 + 小字「coin」，字号与设置页账号卡相同。
- 分隔线下一行价格说明「规则生成 −100 · 困难模式 −300 · 看完广告 +20」，三个数取服务端下发的 `CoinPricing`，价格变了跟着变（2026-10-03 用户裁定保留）。
- 余额取 `CoinWalletStore`，与设置页同一个数；还没拿到时用第一条记录的记账后余额，都没有时写「—」。余额卡不放按钮。
- 下拉刷新时记录与余额一起向服务端对齐。

### 3.2 记录列表

- 按记账时间倒序、按天分组：「今天」「昨天」，更早的写「M月D日」，跨年带年份；组头共用 `CatalogDayTitle`，归组判定共用 `CatalogPersonalTimeline` 的按天判定。
- 同一天的行拼成一张圆角 18 的卡片，行间线从 64pt 起。
- 组头不放当天合计：记录是分页取的，最后一天可能只取到一半。
- 不加「全部 / 获得 / 消耗」筛选（2026-10-03 用户裁定）：分页取的记录筛「获得」可能只剩一两条，图标底色已经分得清进与出。

## 四、记录行

| 位置 | 内容 |
| --- | --- |
| 左 | 36pt 圆形图标。增减为正（获得）用设置页的蓝色图标底与图标色，为负（消耗）用次级填充底与次级色图标 |
| 中·第一行 | 原因，沿用现有三语文案；未知原因显示服务端原文 |
| 中·第二行 | 只写时刻，日期已在组头 |
| 右·第一行 | 增减，等宽数字：获得「+100」用获得色，消耗「−100」（印刷体减号）用主文字色 |
| 右·第二行 | 「余额 1520」，次级色 |

行不可点，不带 ›。进与出按增减正负分，客服调整与未知原因也能正确归类。

获得色是 `CatalogPalette` 的 `gain`：浅色 #248A3D、深色 #30D158（2026-10-03 用户裁定用绿）。浅色不取系统绿 #34C759，它在白底上做文字对比度不到 4.5:1。

| 原因 | 图标 |
| --- | --- |
| 新账号赠送 | `gift.fill` |
| 观看激励广告 | `play.fill` |
| 生成失败退回 | `arrow.uturn.backward` |
| 客服调整 | `person.fill` |
| 规则生成、规则生成（困难模式） | `sparkles` |
| 未知 | `questionmark` |

服务端不下发两笔之间的关联，所以「生成失败退回」不标退回的是哪一次生成。

## 五、其余状态

所有状态都放在同一个可下拉的滚动内容里，余额卡始终在顶部。

| 场景 | 显示 |
| --- | --- |
| 首次加载 | 余额卡照常显示，下方一组与正式行同形的骨架行 |
| 加载失败 | 警示图标 +「无法加载记录」+ 现有说明 + 向下箭头「下拉可重试」；真的能下拉 |
| 没有记录 | 图标 +「还没有记录」+ 现有说明；新账号都有一笔赠送，实际很难出现，不配插画 |
| 下拉刷新失败 | 保留原列表，不换成失败页（`CoinLedgerViewModel` 的现有行为） |
| 翻页中 | 列表末尾一个小转圈 |
| 已到底 | 列表末尾小字「没有更早的记录了」 |
| 未登录或会话失效 | 与加载失败同一显示；设置页只在登录时才有这个入口 |

刷新一律用下拉，不加刷新按钮；页面跟随系统深浅，只用系统底色层级与 `CatalogPalette` 的取值。

## 六、实现位置

- `BrowseCraft/Features/Settings/CoinLedgerView.swift`：隐藏底栏、余额卡、按天分组的卡片行、骨架、可下拉的失败与空状态、翻页与到底提示。
- `BrowseCraft/Features/Settings/Components/SettingsAccountCardView.swift`：推入本页时把 `CoinWalletStore` 一并传入。
- `BrowseCraft/Features/Sources/Catalog/CatalogStyle.swift`：获得色。
- 三份 `Localizable.strings` 末尾「coin 记录页重设计」一段：当前余额、价格说明、到底提示；「下拉可重试」沿用来源页已有的字符串。
