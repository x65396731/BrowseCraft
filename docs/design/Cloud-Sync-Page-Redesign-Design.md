# 云同步页的视觉与信息结构重设计

设计稿（画布，含已开启、未开启、深色、正在同步、未登录 iCloud、同步出错与首次开启窗口两种，共 8 张）：
[云同步页重设计](https://claude.ai/artifact/LctWav1QjBenTHFr3XNNPi)；设计文档：[云同步页重设计](https://claude.ai/artifact/WBwwtB9JSmjsfbd9btZeW3)。
设计与实施状态见 [STATUS.md](../STATUS.md)。颜色、圆角、字号与交互约定沿用设置页、coin 记录页与缓存页
（[设置页](Settings-Page-Redesign-Design.md)、[coin 记录页](Coin-Ledger-Page-Redesign-Design.md)、[缓存页](Cache-Page-Redesign-Design.md)）。

## 一、背景

`CloudSyncSettingsView` 曾是一个系统 `Form`，最多六组：iCloud 账户、开关、同步的内容、立即同步、上次同步、云同步错误。

- 这是设置里的二级页，底栏仍在。
- iCloud 状态与身份关联四行混在一组，两个蓝色按钮夹在两行状态之间；「AnyPortal 身份」「私有 CloudKit 存储」是实现用语。
- 刷新、关联身份、立即同步、重试四个按钮，与「刷新 / 重试用下拉，不加按钮」的约定不符。
- 「上次同步」六行数字平时全是 0。
- 「自定义来源」已不准确（规则只来自目录，`BCA-UI-003`）；「阅读进度 · 暂不支持」让人以为 App 没有这个功能。
- 颜色用系统绿、橙、红，不是 `CatalogPalette` 的取值。

## 二、同步范围（本页只陈述，不改变）

| 内容 | 是否进 iCloud | 页面上怎么写 |
| --- | --- | --- |
| 来源（不含内置来源） | 是 | 「来源」+ 条数 |
| 收藏 | 是 | 「收藏」+ 条数 |
| 历史与阅读进度 | 是，每部作品一条续看记录（[续看位置同步](History-Resume-Sync-Design.md)） | 「历史与阅读进度」+ 作品数 |
| 内置来源 | 否（`BCA-SYNC-009`） | 组下说明「内置来源不占用 iCloud，每台设备自带」 |

条数只数当前仍在的记录：不含删除标记，不含内置来源；历史按作品计数，只数来源还在的。读不到条数时该行不显示数字。

## 三、导航与信息结构

- 从设置页「同步与存储 › 云同步」推入，隐藏底栏，左上系统返回是唯一出口（2026-10-04 用户要求），导航栏居中小标题「云同步」。
- 下拉触发的动作放在独立任务里执行：下拉手势自己的任务会在页面重绘时被系统取消，直接在里面同步会被一并取消。
- 页面上不放按钮（2026-10-04 用户裁定）。下拉承担三件事：重新检查 iCloud；开关开着但账号没有核实时重新关联；
  开关开着且可同步时同步一次，上次出错则按重试触发。
- **状态卡**：56pt 圆形图标 + 标题 + 一句说明，圆角 22，样式与来源页「iCloud 首次恢复」卡（`CloudSyncInitialRestoreView`）一致。
  进行中带转圈；异常时图标与描边换警示色，并写「↓ 下拉可重试」。正常用设置页图标蓝，未开启用次级灰；不用绿，不加插画（同日裁定）。
- **开关**：一行「云同步」+ 系统开关，组下说明「关闭后不会删除任何数据，本机和 iCloud 里的内容都保留」。
- **同步的内容**：第二节那三行，32pt 图标方块。
- **上次同步**：一行小字「上次同步 时间 · 上传 N · 下载 N」，今天的只写时刻；云端删除在本机生效的条数并入「下载」。
  上传失败不为 0 时追加一句警示色「N 项未能上传，下次同步时重试」。「跳过」不显示：它混着正常合并时本机较新而不采用云端的记录。
  没有同步结果时整段不显示。

状态卡只显示一种状态，由 `CloudSyncSettingsViewModel` 的 `statusCard` 按下表从上往下取第一个命中的：

| 状态 | 条件 | 颜色 |
| --- | --- | --- |
| 正在检查 iCloud | 正在检查账户、正在刷新或正在切换开关 | 图标蓝，转圈 |
| 这台设备没有登录 iCloud | 账户状态为未登录 | 警示 |
| iCloud 受到限制 / 暂时不可用 / 无法检查 | 账户状态为对应三种 | 警示 |
| 账号不一致 | iCloud 里的数据属于另一个账号 | 警示 |
| 需要重新验证账号 | 开关开着但当前账号没有核实过 | 警示 |
| 正在同步 | 同步进行中 | 图标蓝，转圈 |
| 同步没有完成 | 有错误信息。开启过程的错误直接显示其文案；同步过程的错误显示通用说明「本机的改动已保留，会在下次同步时上传」，脱敏后的技术文字放在下面的小字里供排查 | 警示 |
| 已同步到 iCloud | 开关开着 | 图标蓝 |
| 云同步未开启 | 其余 | 次级灰 |

「正在同步」排在「同步没有完成」之前：下拉重试时先看到进行中，而不是上一次的错误。

## 四、开启、关闭与首次开启窗口

- 打开开关时自动检查 iCloud 并自动关联账号，不需要单独的关联按钮（2026-10-04 用户裁定）。
- 打开开关而 iCloud 不可用时不弹提示框：开关弹回，状态卡显示原因（同日裁定）。
- 关闭开关直接生效，不弹确认。
- **首次开启窗口**与本页同一套卡片样式（同日裁定），只改外观与文案，两个选择的含义不变：
  内容里自绘大标题「首次云同步」，左上「取消」；一句说明写清存什么。
  - 本机有来源或收藏：小标题「本机已有 N 个来源、N 个收藏」，两张入口卡「合并本机数据」「只用 iCloud 数据」，
    下面一句「两种选择都不会删除本机现有的数据」。
  - 本机没有：一个蓝色主按钮「开启云同步」，下面一句「确认之前不会上传任何内容」。
  - 提交中两张卡都禁用，没被点的那张变淡，被点的那张行尾换成转圈；提交中不能下滑关闭。出错时卡片下方一行警示色文字。
- 页面跟随系统深浅，只用系统底色层级与 `CatalogPalette` 的取值。

## 五、不改的东西

- 同步引擎、触发时机、合并与删除规则、上传前安全门禁、身份与账户作用域（`BCA-SYNC-001` ~ `BCA-SYNC-011`）。
- 来源页与收藏页上的「iCloud 首次恢复」卡片及其下拉重试。
- 设置页「云同步」行右侧的状态说明。

## 六、实现位置

- `BrowseCraft/Features/Settings/CloudSync/CloudSyncSettingsView.swift`：隐藏底栏、状态卡、开关、同步的内容、上次同步、下拉、首次开启窗口。
- `BrowseCraft/Features/Settings/CloudSync/CloudSyncSettingsViewModel.swift`：`statusCard`、条数（`syncedContentSummary`）与下拉入口 `refreshFromPull`。
- `BrowseCraft/Application/Ports/Sync/CloudAccountPartitioning.swift` 与
  `BrowseCraft/Infrastructure/Database/Sync/GRDBCloudAccountPartitionStore.swift`：读「同步的内容」条数。
- 入口卡复用来源页的 `SourcesEntryCardView`，卡片组与行间线复用 `SettingsCardGroup`、`SettingsRowSeparator`。
- 三份 `Localizable.strings` 末尾「云同步页重设计」一段；原页面不再使用的词条已删除。

## 七、真机验收清单

- 进入后底栏隐藏；状态卡各状态（未开启、正在检查、正在同步、已同步）；页面上没有按钮，下拉即同步。
- 首次开启窗口两张入口卡；「同步的内容」三行的条数。
- 模拟器没看到、真机顺带看：未登录 iCloud 的状态卡、同步出错卡下面的小字技术文字、首次开启窗口的提交中状态。深色模式整页看一遍。
