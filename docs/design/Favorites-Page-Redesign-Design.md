# 收藏页的视觉与信息结构重设计

设计稿（画布，含浅色 / 深色、类型筛选、左滑与撤销、长按菜单、来源状态、空状态、iCloud 恢复失败与某类型为空，共 10 张）：
[收藏页重设计](https://claude.ai/artifact/BVUs1rspjfmcotrydftfxo)。设计与实施状态见 [STATUS.md](../STATUS.md)。
颜色、圆角、字号、组件与交互约定沿用来源页与规则目录页（[来源页](Sources-Page-Redesign-Design.md)、[规则目录页](Catalog-Page-Redesign-Design.md)第三节），本页不新增类型色。

## 一、背景

`FavoritesView` 是一个系统分组列表，每行由 `FavoriteEntryRowView` 画成「类型图标 + 标题 / 来源名 / 详情 / 日期」四行，
与重设计后的来源页、规则目录页并排在底栏时反差明显：

- 导航栏大标题「收藏」下面又有一个分组头「收藏」。
- 数据里有封面地址，页面却只显示文字；类型只靠灰色小图标区分。
- 没有「更新到第 N 集」时把详情页完整地址显示成一行。
- 不能在本页取消收藏；所有类型混在一列；来源找不到时显示未本地化的英文。

## 二、信息结构

### 2.1 顶部

- 大标题「收藏」靠左，在内容里自绘；右侧一个小字「N 个收藏」。
- 标题下一个分段筛选「全部 | 视频 | 漫画 | 书籍」，样式与目录页「推荐 | 我的生成」相同（共用 `CatalogSegmentedPicker`），每段带计数。
  「全部」与三个类型标签一直显示，没有收藏的类型计数为 0（2026-10-03 用户裁定）。

### 2.2 列表

- 「全部」和每个类型标签下都按收藏时间倒序、按天分组（2026-10-02 用户裁定，不按来源分组）：「今天」「昨天」，更早的写「M月D日」，
  跨年时带年份。组头文字与目录页「我的生成」时间线共用 `CatalogDayTitle`。
- 同一天的行拼成一张圆角 18 的卡片组：首行圆上角、末行圆下角，行间细线从 82pt 起（来源页的来源行是 68pt，结构同、起点不同）。

### 2.3 卡片行

| 位置 | 内容 |
| --- | --- |
| 左 | 封面 56×78pt，圆角 10，经 `ItemThumbnailImageView` 走库页同一个封面管线，请求配置取该来源规则的图片请求配置；无封面时退回该类型的占位图 |
| 封面左下角 | 18pt 类型徽标：类型色底 + 类型图标，同时用颜色与图标区分 |
| 中·第一行 | 作品名，最多两行 |
| 中·第二行 | 来源名 |
| 中·第三行 | 最新状态（「更新到第 N 集」等），没有就不显示；不再显示完整地址 |
| 右 | › |

收藏时间不逐行显示，由分组头承担。

### 2.4 点击语义

- **点行**：进作品详情（视频 / 漫画 / 站点书详情），与现在相同。
- **左滑**：「取消收藏」，按钮为删除色 `#E5484D`，不弹确认（2026-10-02 用户裁定）。
- **长按菜单**：「打开」「在库中查看来源」（切到该来源并打开库，与来源页「点来源即打开库」同一条路径）、分隔开的红色「取消收藏」。
- **撤销**：取消收藏后底部出现反色胶囊提示「已取消收藏「作品名」 · 撤销」，约 4 秒后消失；点撤销按原收藏时间恢复，条目回到原来的日期分组。
- 本页改动收藏后，库页封面上的爱心状态必须跟着刷新。

## 三、其余状态

| 场景 | 显示 |
| --- | --- |
| 没有收藏 | 插画 `EmptyStateFavorites` +「还没有收藏」+ 一句说明，下面一张入口卡片「去库里逛逛」切到库标签；空状态放在滚动内容里 |
| 某个类型没有收藏 | 该标签下显示小空状态：类型图标 +「还没有收藏的书籍」+ 一句说明，不用插画；取消收藏使当前类型变空时停在该标签 |
| iCloud 首次恢复 | 共用 `CloudSyncInitialRestoreView` 卡片与两条骨架；失败时下拉重试，其余时候下拉重新读本地收藏 |
| 来源已暂停（位置不够） | 来源名后加橙色「· 已暂停」；点行打开来源页的启用来源窗口，而不是进一个打不开的详情 |
| 来源已删除 | 用收藏时保存的来源快照照常显示，来源名后加「· 来源已删除」，整行变淡；点行仍尝试打开详情 |
| 来源找不到且没有快照 | 来源名显示「未知来源」，整行变淡、没有 ›，点行无反应，只能左滑或长按取消收藏 |

用户在本机删除来源时收藏会一并删除（[删除来源时连带删除历史与收藏](Source-Deletion-Cascade-Design.md)），所以「来源已删除」「未知来源」两种行只作兜底：主要来自 iCloud 区域被清除、「只用 iCloud 数据」、旧版本设备删除的来源，以及此前留下的数据。

## 四、不变的部分

- 收藏的数据、同步与详情页不变；本设计只改信息组织与外观，并新增「在本页取消收藏」「撤销」「在库中查看来源」三个入口。
- 撤销按原收藏时间恢复：仓储 `FavoriteRepository` 提供按条目自带收藏时间重新收藏的写法，普通收藏仍记当前时间。

## 五、实现位置

- `BrowseCraft/Features/Favorites/FavoritesView.swift`：顶部、类型筛选、按天分组的卡片行、左滑与长按、撤销提示、空状态与恢复态。
- `BrowseCraft/Features/Favorites/FavoritesViewModel.swift`：筛选计数、按天分组、来源状态、封面请求配置缓存、取消与撤销收藏。
- `BrowseCraft/Features/Sources/Catalog/CatalogStyle.swift`：`CatalogSegmentedPicker` 与反色提示条上的动作色。
- `BrowseCraft/Features/Sources/Catalog/CatalogPersonalTimeline.swift`：按天归组与 `CatalogDayTitle`，目录页与收藏页共用。
- `BrowseCraft/App/RootView.swift`：收藏页请求「去库里逛逛」「在库中查看来源」「启用来源」时切标签；收藏页改动后让库页刷新爱心状态。

## 六、真机验收清单

- 「全部 | 视频 | 漫画 | 书籍」一直显示、某类为 0 的小空状态；按天分组。
- 左滑与长按取消收藏不弹确认，底部撤销按原日期恢复；「在库中查看来源」。
- 已暂停 / 已删除 / 未知来源三种行；取消收藏后库页爱心同步。
- 深色模式整页看一遍。iCloud 首次恢复失败的下拉重试在真机上不易触发，可不强求。
