# 收藏页的视觉与信息结构重设计

设计稿（画布，含浅色 / 深色、类型筛选、左滑、选择模式与批量确认、长按菜单、来源状态、空状态、iCloud 恢复失败与某类型为空，共 11 张）：
[收藏页重设计](https://claude.ai/artifact/BVUs1rspjfmcotrydftfxo)。设计与实施状态见 [STATUS.md](../STATUS.md)。
颜色、圆角、字号、组件与交互约定沿用来源页与规则目录页（[来源页](Sources-Page-Redesign-Design.md)、[规则目录页](Catalog-Page-Redesign-Design.md)第三节），本页不新增类型色。

## 一、背景

`FavoritesView` 是一个系统分组列表，每行由 `FavoriteEntryRowView` 画成「类型图标 + 标题 / 来源名 / 详情 / 日期」四行，
与重设计后的来源页、规则目录页并排在底栏时反差明显：

- 导航栏大标题「收藏」下面又有一个分组头「收藏」。
- 数据里有封面地址，页面却只显示文字；类型只靠灰色小图标区分。
- 没有「更新到第 N 集」时把详情页完整地址显示成一行。
- 不能在本页取消收藏；所有类型混在一列；来源找不到时显示未本地化的英文。

## 二、信息结构

### 2.1 顶部

- 大标题「收藏」靠左，在内容里自绘；右侧一个「选择」按钮（2026-10-17 用户裁定；不写总数，总数看「全部」段）。当前筛选下没有收藏时按钮变灰不可点。
- 标题下一个分段筛选「全部 | 视频 | 漫画 | 书籍」，样式与目录页「发现 | 我的生成」相同（共用 `CatalogSegmentedPicker`），每段带计数。
  「全部」与三个类型标签一直显示，没有收藏的类型计数为 0（2026-10-03 用户裁定）。

### 2.2 列表

- 「全部」和每个类型标签下都按收藏时间倒序、按天分组（2026-10-02 用户裁定，不按来源分组）：「今天」「昨天」，更早的写「M月D日」，
  跨年时带年份。组头文字与目录页「我的生成」时间线共用 `CatalogDayTitle`。
- 同一天的行拼成一张圆角 18 的卡片组：首行圆上角、末行圆下角，行间细线从 82pt 起，选择模式下（前面多了勾选框）从 118pt 起（来源页的来源行是 68pt，结构同、起点不同）。

### 2.3 卡片行

| 位置 | 内容 |
| --- | --- |
| 左 | 封面 56×78pt，圆角 10，经 `ItemThumbnailImageView` 走库页同一个封面管线，请求配置取该来源规则的图片请求配置；无封面时退回该类型的占位图 |
| 封面左下角 | 18pt 类型徽标：类型色底 + 类型图标，同时用颜色与图标区分 |
| 中·第一行 | 作品名，最多两行 |
| 中·第二行 | 来源名 |
| 中·第三行 | 最新状态（「更新到第 N 集」等），没有就不显示；不再显示完整地址 |
| 右 | › |

收藏时间不逐行显示，由分组头承担。

### 2.4 点击语义

- **点行**：进作品详情（视频 / 漫画 / 站点书详情），与现在相同。
- **左滑**：露出删除色 `#E5484D`「取消收藏」按钮，再点一下按钮才取消，不支持一滑到底（没有撤销，靠这一步防误触）；不弹确认。
- **长按菜单**：「打开」「在库中查看来源」（切到该来源并打开库，与来源页「点来源即打开库」同一条路径）、「选择多项」（进入选择模式并预先选中这一条）、分隔开的红色「取消收藏」。
- **不提供撤销**（2026-10-17 用户裁定）：取消收藏立即生效，底部不再出现撤销提示。
- 本页改动收藏后，库页封面上的爱心状态必须跟着刷新。

### 2.5 选择与批量取消收藏

本节为设计稿新增的选择模式（2026-10-17 用户确认）：

- **进入**：点标题行「选择」，或长按菜单「选择多项」（预先选中那一条）。
- **标题行**：大标题换成「已选择 N 部」，右侧实心添加蓝「完成」退出。
- **类型筛选**：变淡、不可切换；「全选」只选当前筛选下的条目，全部选中后变「全不选」。
- **行**：行首 24pt 圆形勾选框（选中为添加蓝底白勾，未选为灰色圆环），选中行铺一层浅添加蓝；点整行切换选中，不进详情、不能左滑、没有长按菜单、不显示 ›。
- **底栏**：换成操作栏：「全选 / 全不选」、「已选 N 部」、红色「取消收藏」；一条没选时按钮禁用。
- **确认**：点「取消收藏」弹居中确认框「取消收藏 N 部作品？」+「取消后无法撤销，需要时可以在库里重新收藏。」，按钮「保留」与红色「取消收藏」（不用「取消」，免得和「取消收藏」挨在一起看混）。确认后退出选择模式。
- **退出**：点「完成」、确认取消收藏后、切走标签、页面被锁定（[面容 ID 锁定](Content-Lock-Design.md)）或收藏变空时退出，不保留勾选。

## 三、其余状态

| 场景 | 显示 |
| --- | --- |
| 没有收藏 | 插画 `EmptyStateFavorites` +「还没有收藏」+ 一句说明，下面一张入口卡片「去库里逛逛」切到库标签；空状态放在滚动内容里 |
| 某个类型没有收藏 | 该标签下显示小空状态：类型图标 +「还没有收藏的书籍」+ 一句说明，不用插画；取消收藏使当前类型变空时停在该标签 |
| iCloud 首次恢复 | 独立的一页 `ScrollView`：标题行（不带计数）+ 共用的 `CloudSyncInitialRestoreView` 卡片 + 两条骨架，不叠在列表上；失败时下拉重试，其余时候下拉重新读本地收藏 |
| 来源已暂停（位置不够） | 来源名后加橙色「· 已暂停」；点行打开来源页的启用来源窗口，而不是进一个打不开的详情 |
| 来源已删除 | 用收藏时保存的来源快照照常显示，来源名后加「· 来源已删除」，整行变淡；点行仍尝试打开详情 |
| 来源找不到且没有快照 | 来源名显示「未知来源」，整行变淡、没有 ›，点行无反应，只能左滑或长按取消收藏 |

删除来源时收藏保留（[删除来源时保留历史与收藏](Source-Deletion-Cascade-Design.md)），所以「来源已删除」是常见状态：点行用收藏时存的来源快照照常打开详情。「未知来源」只来自没有快照的旧数据。

## 四、不变的部分

- 收藏的数据、同步与详情页不变；本设计只改信息组织与外观，并新增「在本页取消收藏」「批量取消收藏」「在库中查看来源」三个入口。

## 五、实现位置

- `BrowseCraft/Features/Favorites/FavoritesView.swift`：顶部、类型筛选、按天分组的卡片行、左滑与长按、选择模式与操作栏、批量确认框、空状态与恢复态。
- `BrowseCraft/Features/Favorites/FavoritesViewModel.swift`：筛选计数、按天分组、来源状态、封面请求配置缓存、取消收藏、选择与批量取消收藏。
- `BrowseCraft/Features/Shared/ContentSelectionComponents.swift`：收藏页与历史页共用的勾选框、标题行按钮与选择操作栏。
- `BrowseCraft/Features/Sources/Catalog/CatalogStyle.swift`：`CatalogSegmentedPicker`。
- `BrowseCraft/Features/Sources/Catalog/CatalogPersonalTimeline.swift`：按天归组与 `CatalogDayTitle`，目录页与收藏页共用。
- `BrowseCraft/App/RootView.swift`：收藏页请求「去库里逛逛」「在库中查看来源」「启用来源」时切标签；收藏页改动后让库页刷新爱心状态。

## 六、真机验收清单

- 「全部 | 视频 | 漫画 | 书籍」一直显示、某类为 0 的小空状态；按天分组。
- 左滑要再点按钮才取消、不弹确认、没有撤销；长按「在库中查看来源」「选择多项」。
- 选择模式：全选只选当前筛选、操作栏、确认框、确认后退出；锁定或切走标签退出选择模式。
- 已暂停 / 已删除 / 未知来源三种行；取消收藏后库页爱心同步。
- 深色模式整页看一遍。iCloud 首次恢复失败的下拉重试在真机上不易触发，可不强求。
