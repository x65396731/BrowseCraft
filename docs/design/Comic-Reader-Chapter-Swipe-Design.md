# 漫画阅读器的换话手势

设计稿（画布，含进下一话四步、回上一话四步、最后一话、第一话、从历史进来不能换、本话没有页面、换话失败、深色两张、尺寸与取值，共 16 张）：
[漫画阅读器换话手势](https://claude.ai/artifact/6uk6Quc2b5kz8JoVS88HGi)；设计文档是 Claude 文档「漫画阅读器换话手势设计书」，从「BrowseCraft 页面设计索引」的漫画阅读器一行进入。
设计与实施状态见 [STATUS.md](../STATUS.md)。阅读器从[漫画详情与章节页](Comic-Detail-Page-Redesign-Design.md)、[库页漫画库](Library-Comic-Page-Redesign-Design.md)的「上次读到」瓷砖与[历史页](History-Page-Redesign-Design.md)推入；
换话等待用的标记见[品牌等待标记](Brand-Waiting-Mark-Design.md)。

## 一、范围

漫画阅读器是自己写的纵向滚动列表（Nuke 只负责每一页图片的下载、缓存与解码，没有阅读器界面）。换话不用按钮：
读到末页继续上拉进下一话，在第一页继续下拉回上一话，与纵向阅读时手指的自然方向一致。末页下方的「上一话 / 下一话」按钮组已删除，
标题栏仍只显示当前话名，不加目录或换话入口。

不在本文范围：每页图片的加载、降采样与受保护图片解密；阅读进度记录与续读恢复；按话累计广告积分与激励广告门；受限章节的登录墙；
换话埋点（`chapter_opened` 按上一话 / 下一话记方向）。手势只换了触发方式，换话后照常走这些流程。

## 二、前后话从哪里来

| 来源 | 从哪里来 | 什么时候有 |
| --- | --- | --- |
| 章节页自己给的链接 | 规则阅读页解析出的 `previousChapterURL` / `nextChapterURL` | 规则声明了这两个字段的站点 |
| 详情页的目录顺序 | 从详情页点进来时带着整份目录与方向，按当前话在目录里的位置推出前后一话 | 从详情页进入时一定有 |

先用第一个，没有才用第二个。目录方向与详情页「第 1 话在哪一头」同一套推断：先按首尾话数推断正序还是倒序，推断不出来才用规则声明的排序，
规则也没声明按倒序（`ComicDetailViewModel.readerNavigationOrder`）。库页「上次读到」瓷砖与历史页行只带一条阅读历史、不带目录，
只能靠章节页自己给的链接；规则没声明链接的站点，从这两个入口进来前后都换不了。

某个方向能不能换由 `ReaderChapterSwitchAvailability` 表达：有地址是「能换」，带目标话名（话名取目录里的标题，没有目录时不带）；
带着目录进来、或规则给了另一个方向的链接，说明只是到头了；两者都没有就是「这里不能切换」。

## 三、两个手势

**底部上拉进下一话**：

1. 读到末页底端后继续往上推，内容下方拉出一段空白，里面是向上的箭头和「上拉进入下一话 · 第 2 话」。
2. 拉过触发距离后，文字变为「松手进入下一话」，箭头翻转，轻震一次；往回拉到触发距离以内恢复原样。
3. 松手、回弹停稳后，贴底浮层里显示中号品牌等待标记和「正在打开第 2 话」，当前这一话的内容不动。
4. 新的一话换上后从第一页顶端开始，标题栏换成新的话名。
5. 没拉到触发距离就松手只回弹，不换话。

**顶部下拉回上一话**与上拉对称：停在第一页顶端继续往下拉，提示「下拉回到上一话 · 第 1 话」，过距离变「松手回到上一话」，
等待浮层贴在标题栏下。回到上一话落在它的**第一页**，不做任何程序滚动。

两个手势只在滚到头之后才起作用，阅读中间的正常上下滑动与惯性滑到头的回弹都不触发。首次加载中、重试中、换话进行中两个手势都不响应。

## 四、其余状态

| 状态 | 表现 |
| --- | --- |
| 第一次加载中 | 页面中间转圈，两个手势不响应 |
| 没有下一话（最后一话） | 上拉时只提示「已经是最后一话」，没有箭头，不进入松手态，松手回弹 |
| 没有上一话（第一话） | 下拉时只提示「已经是第一话」，同上 |
| 从历史进来且规则没给前后链接 | 两个方向都只提示「这里不能切换，可以回详情页选话」 |
| 换话中 | 贴边浮层里品牌等待标记 +「正在打开 …」，当前这一话照常可滑 |
| 换话失败 | 浮层收起，留在原话，弹系统提示框「阅读器」+ 错误分类器的三语短句；关掉后可以再拉一次 |
| 本话加载失败或没有页面 | 现有「没有页面」说明下加「下拉重试」：顶部下拉是重试本话（守住「重试用下拉」的约定），底部上拉仍进下一话；说明撑满一屏，从说明下方的空白处拉也能触发 |
| 受限章节 | 拉到受限的下一话同样弹登录提示，登录后直接换上那一话 |
| 广告门 | 换上新一话后照常按话计分、弹激励广告 |

页面设计索引的交互约定里「刷新 / 重试用下拉」「底部上拉是触底加载下一页」在阅读器里是例外：阅读器一话的图一次拿全、没有分页加载，
底部上拉不冲突；顶部下拉只在本话没有页面时是重试。

## 五、时机与滚动

同一个滚动视图里有三个时刻会和手指打架：手指按着时改偏移会被忽略或跳一下；松手后的回弹动画里换内容会闪或停错位置；
每页用页码当身份时新旧两话是同一组数字，系统可能沿用旧的滚动位置。

- `BCA-UI-008` 漫画阅读器换话时程序不改滚动偏移量，也不为等待锁住页面。拉过触发距离只记下「待换话」，等滚动回到静止
  （手指离开、回弹停稳）才发起；新的一话取到后先挂起，同样等滚动静止才换上。每一话用以这一话地址为身份的独立滚动视图，
  换上时新建，天然从第一页顶端开始。等待期间当前这一话照常滑动，点返回取消正在进行的加载，贴边等待浮层只负责显示、不接收触摸，
  只有两个换话手势不响应。阅读器唯一的主动滚动是从历史进入时恢复上次页码：在新视图布局完成后执行，用户已经碰了屏幕就放弃。

读拉出距离与滚动阶段用 iOS 18 引入的滚动几何与滚动阶段接口，App 最低系统版本因此是 iOS 18（[architecture.md](../architecture.md) 第 8 节）；
系统自带的下拉刷新只管顶部、空白里只能放转圈，不用它。拉出距离与拉动状态放在 `ReaderPullTracker` 里而不是阅读器视图的状态里，
拉动的每一帧只刷新提示，不重算整列漫画页。

## 六、视觉

- 拉动提示与失败态「下拉重试」同一套：系统 `chevron.compact` 箭头 20pt semibold + footnote 一行，间距 4，居中放在拉出的空白里；
  拉动中次级色，过距离后主色 semibold；单行，话名过长尾部省略。不加卡片、不加按钮。不能换的三种情况只有文字、没有箭头。
- 触发距离 72pt（`ReaderPullTracker.triggerDistance`），在真机上微调。
- 换话等待：中号 56pt `BrandWaitingMark` + footnote 次级色，间距 8；放在高 100、底色同页面、带分隔线的贴边浮层里，进下一话贴底、
  回上一话贴在标题栏下。浮层不属于滚动内容，松手回弹停稳后拉出的空白已经收回，所以不放在空白里。
- 阅读器背景保持页面底色，跟随系统浅色 / 深色；漫画图本身不反色。
- 读屏：上拉、下拉在 VoiceOver 下做不了，每一页漫画图上挂「下一话」「上一话」两个读屏操作（上下轻扫选、双击执行），
  只在那个方向能换时出现，执行的是同一个发起换话；开始换话时读出与浮层同一句「正在打开 …」。不用读屏三指滑动映射手势：
  那会接管整个滚动视图的读屏滚动，连带影响正常翻页。

## 七、文案

| 用途 | 词条 | 简中 |
| --- | --- | --- |
| 上拉中 | `reader_swipe_next_hint` / `_plain` | 上拉进入下一话 · %@ / 上拉进入下一话 |
| 上拉过距离 | `reader_swipe_next_release` | 松手进入下一话 |
| 下拉中 | `reader_swipe_previous_hint` / `_plain` | 下拉回到上一话 · %@ / 下拉回到上一话 |
| 下拉过距离 | `reader_swipe_previous_release` | 松手回到上一话 |
| 换话中 | `reader_swipe_opening` / `_opening_next` / `_opening_previous` | 正在打开 %@ / 正在打开下一话 / 正在打开上一话 |
| 没有下一话 | `reader_swipe_last_chapter` | 已经是最后一话 |
| 没有上一话 | `reader_swipe_first_chapter` | 已经是第一话 |
| 换不了 | `reader_swipe_unavailable` | 这里不能切换，可以回详情页选话 |
| 读屏操作 | `reader_swipe_action_next` / `reader_swipe_action_previous` | 下一话 / 上一话 |
| 本话没有页面时 | `video_detail_pull_retry`（与各页失败态共用） | 下拉重试 |

没有话名时用 `_plain` 那一条。三语词条同时存在于 en、zh-Hans、zh-Hant。

## 八、实现位置

- `ReaderView`：每一话独立的滚动视图、读拉出距离与滚动阶段、松手后等静止发起、挂起的新一话等静止换上、拉动提示与贴边等待浮层、
  本话没有页面时的「下拉重试」、离开时取消换话、每页的读屏换话操作与开始换话时的读屏播报。
- `ReaderViewModel`：`startChapterSwitch` 发起换话并挂起结果、`showLoadedChapter` 换上、`cancelChapterSwitch` 取消、
  `retryCurrentChapter` 重试本话、`chapterSwitchAvailability` 给提示用的能否换与目标话名；换上时才记历史、计分与报 `chapter_opened`。
- `Components/ReaderChapterSwipe.swift`：`ReaderOverscroll`、`ReaderPullTracker`、`ReaderPullHintsOverlay`、`ReaderChapterSwitchWaitingBand`。
  底部拉出距离按「滚动几何的可视高度已扣掉上下内边距」算：滚到底时的偏移是内容高减可视高再减顶部内边距。
- 失败提示与登录提示分挂两层，都用带 actions / message 的提示框写法：旧的 `Alert` 写法在这个推入页里弹不出来
  （库页根视图也挂着一个旧写法的弹框），失败时用户看不到任何原因。
