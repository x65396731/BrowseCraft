**説明（4,000）**
```
AnyPortalは「サイトのルール」で動くリーダーです。あるサイトのカテゴリ一覧ページのURLを貼ると、サーバーがページ構造を解析して読むためのルールを1つ生成します。その後はそのサイトがソースとしてあなたの本棚に並び、一覧、作品ページ、章、閲覧ページのすべてをAppがネイティブに表示します。

対応する内容は4種類：小説、マンガ、動画、オーディオブック。

使い方
• 「カタログ › マイ生成」でサイトのカテゴリ一覧ページ（ページ番号があり、作品が並んでいるページ）のURLを貼り、内容の種類を選んで送信します。
• 生成はたいてい数分で終わり、完了すると通知でお知らせします。失敗したときは理由を表示し、やり直せるものはやり直せます。
• 「見つける」にはサイト例があり、＋をタップするだけで追加できます。
• お気に入り、読書の進み具合、履歴はあなたの端末に保存されます。iCloud同期をオンにするとあなたの端末同士で同期され、私たちはアクセスできません。

coin
• 新規アカウントに3,000 coinをプレゼント。リワード広告を見るごとに+20。App内で購入もできます。
• 通常の生成は1回100 coin、ハードモードの生成は1回300 coin。費用のかからなかった失敗は返却されます。

内容とプライバシー
• 追加したサイトの内容は、あなたの端末がそのサイトに直接接続して読み込みます。私たちのサーバーは経由しません。
• アカウントは「Appleでサインイン」のみ。氏名やメールアドレスを求めることも保存することもありません。
• プライバシーポリシー：https://anyportal.online/privacy
• サポート：https://anyportal.online/support

AnyPortalはいかなる内容も提供せず、あなたが追加したサイトについて責任を負いません。各サイトの利用規約に従ってください。
```
